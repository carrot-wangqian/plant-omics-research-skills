# Synthetic reading report

A deliberately fictional example. It is not a real paper, dataset, citation, or demonstration of a completed analysis.

| Item | Example entry |
| --- | --- |
| Source and access | Fictional reading example. Synthetic panel 2B and accompanying mock caption only. No DOI, real unit counts or raw data. |
| Design | Illustrative edge/interior comparison within a leaf. The data hierarchy, sample sizes and statistical test are not specified. |
| Observation | Signal appears stronger near the leaf edge in synthetic panel 2B. This is a visual comparison, not a quantified difference. |
| Method | The two mock panels use a shared intensity scale. Acquisition settings and preprocessing are not reported in this example. |
| Interpretation | The pattern could motivate a follow-up comparison across independent samples. It does not establish molecular identity, enrichment or cause. |
| Reuse check | Before comparing actual panels, verify the intensity scale and identify the independent samples. If the sampling design is unavailable, mark it unverified. |
| Optional follow-up | If asked, save the source locator, reading basis, unresolved settings and the next question to verify. |
