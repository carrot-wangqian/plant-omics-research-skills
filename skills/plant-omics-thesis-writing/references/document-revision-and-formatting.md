# Document revision and formatting

Use the author's selected document as the baseline. Preserve, respond to, resolve, or accept comments and tracked revisions only within the current scope. Distinguish already resolved notes and items expressly deferred by the author. If an issue is outside scope, identify its location instead of silently changing it.

Use any supplied institution or journal specification as a separate input, not a bundled universal format. Record the chosen baseline or template and only the applicable rules: page geometry and section breaks; headings and numbering; captions, figures and tables; language and citation style; reference fields and bibliography. Keep native fields and body text editable. Do not claim a requirement was met if the relevant specification or rendering is unavailable.

Compare the revised document to the original in areas that should not change. When tools permit, render the exported file and inspect affected pages for heading hierarchy, captions, split tables, formulas, superscripts, symbols, and image quality. A DPI setting is not proof of resolution: use original pixel dimensions and placed size. If a citation manager is unavailable, retain a proposed citation location and verified reference identity instead of simulating dynamic fields.

Return the requested deliverables and a short list of unresolved issues that affect the manuscript. A tracked and clean copy should retain the same evidence basis.
